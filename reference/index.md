# Package index

## Functions

Functions for fetching data from Quality of Government website

- [`read_qog()`](read_qog.md) : Retrieve and Read Quality of Government
  Institute data in R
- [`run_app()`](run_app.md) : Run an on-board Shiny app to browse the
  metadata and data availability of Quality of government data
