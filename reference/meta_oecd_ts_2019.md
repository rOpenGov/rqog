# Metadata for 2019 Quality of Government institute OECD Data - time-series

Generated automatically from spss-version of Quality of Government OECD
data using `tidymetadata::create_metadata()` function. Formatted in
tidy-format with row per each value of an indicator. Numeric indicators
have a single row per indicator.

## Usage

``` r
meta_oecd_ts_2019
```

## Format

A data frame with 1390 rows and five columns

- code:

  Indicator code in data

- name:

  Name of the indicator

- value:

  Indicator value for factor indicator

- label:

  Value label for factor indicators

- class:

  Class of the indicator. Numeric, factor or character
